

# DotD

DotD es un proxy DNS sobre HTTPS simple y flexible con resolver personalizado y otras ventajas.

## Instalación

DotD es compatible con macOS, Linux y Windows.

### Binarios (macOS, Linux y Windows)

Los archivos de los binarios están disponibles en [cada versión](https://github.com/adnsio/dotd/releases).

### Homebrew (macOS y Linux)

```
brew install adnsio/tap/dotd
```

## Cómo usar

Simplemente ejecute `dotd server` y luego configure `::1` para IPv6 y/o `127.0.0.1` para IPv4 como servidor DNS principal.
